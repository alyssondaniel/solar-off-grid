## Sequencia recomendada

1. Ler [anenji-manual-final-anj4000-24v.md](anenji-manual-final-anj4000-24v.md)
2. Configurar com [anenji-passo-a-passo-painel-anj4000-24v.md](anenji-passo-a-passo-painel-anj4000-24v.md)
3. Marcar em [anenji-checklist-configuracao-anj4000-24v.md](anenji-checklist-configuracao-anj4000-24v.md)
4. Operar no dia a dia com [anenji-operacao-rapida-cenario-atual.md](anenji-operacao-rapida-cenario-atual.md)
5. Validar combinacoes em [anenji-quadro-semaforo-cargas.md](anenji-quadro-semaforo-cargas.md)
6. Se houver necessidade de duas pesadas, validar em [anenji-matriz-duas-cargas-pesadas.md](anenji-matriz-duas-cargas-pesadas.md)
7. Em evento critico, executar [anenji-plano-contingencia.md](anenji-plano-contingencia.md)
8. Se a bateria amanhecer zerada, executar [anenji-amanheceu-zerada-diagnostico-5-min.md](anenji-amanheceu-zerada-diagnostico-5-min.md)
9. Para acao imediata, usar [anenji-cartao-amanheceu-zerada-10-linhas.md](anenji-cartao-amanheceu-zerada-10-linhas.md)
10. Para option/code detalhado, consultar [anenji-opcoes-paginas-11-17-4-2kw.md](anenji-opcoes-paginas-11-17-4-2kw.md)
11. Para uso em campo sem abrir varios arquivos, usar [anenji-cartao-campo-1-pagina.md](anenji-cartao-campo-1-pagina.md)
12. Para impressao em parede e checklist diario visual, usar [anenji-folha-parede-a4.md](anenji-folha-parede-a4.md)
13. Para laminar e manter junto ao display, usar [anenji-etiqueta-laminada-meia-pagina.md](anenji-etiqueta-laminada-meia-pagina.md)
14. Para colar no painel com minimo texto, usar [anenji-adesivo-mini-painel.md](anenji-adesivo-mini-painel.md)
