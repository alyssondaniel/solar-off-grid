# Passo a passo no painel - ANENJI ANJ-4000W-24V

## Objetivo

Aplicar uma configuracao operacional conservadora e segura para as cargas do seu cenario.

## Entrada no menu

1. ligar bateria e aguardar inicializacao
2. entrar no menu de parametros pelo painel
3. navegar item por item usando setas e confirmacao

## Sequencia recomendada

1. programa 01 -> SBU priority
2. programa 02 -> 60A
3. programa 08 -> 230V
4. programa 09 -> 60Hz
5. programa 10 -> manual
6. programa 11 -> 10A ou 20A
7. programa 12 -> 25.5V
8. programa 13 -> 26.5V
9. programa 16 -> Only Solar (dia a dia)
10. programa 26 -> 28.2V a 28.4V
11. programa 27 -> 27.0V
12. programa 29 -> 24.0V
13. programa 33 -> disable
14. programa 39 -> disable
15. programa 45 -> 20%
16. salvar e sair do menu

## Validacao em campo

1. ligar apenas cargas leves
2. observar estabilidade por alguns minutos
3. testar uma carga pesada por vez
4. confirmar ausencia de alarmes

## Se algo sair do esperado

- reduzir para cargas essenciais
- revisar prioridade de carga e limite AC
- evitar carga pesada simultanea
