# Quadro semaforo - SUMRY SP-4200

## Faixas

- VERDE: ate 1500W
- AMARELO: 1500W a 2500W
- VERMELHO: acima de 2500W (evitar acima de 3000W)

## Equipamentos

| Equipamento              | Faixa   | Regra                   |
| ------------------------ | ------- | ----------------------- |
| Geladeira                | VERDE   | manter ligada           |
| Purificador 110W         | VERDE   | uso livre               |
| TVs + notebooks          | VERDE   | uso livre               |
| Ar condicionado 9000 BTU | AMARELO | evitar junto com pesada |
| Cafeteira 600W           | AMARELO | uso curto               |
| Maquina 1500-1900W       | AMARELO | 1 pesada por vez        |
| Air fryer 1700W          | AMARELO | 1 pesada por vez        |
| Fogao 2000W              | AMARELO | 1 pesada por vez        |

## Combinacoes proibidas

- maquina + air fryer
- maquina + fogao
- air fryer + fogao
- fogao + air fryer + ar condicionado

## Regra final

- pesado desliga primeiro, leve volta primeiro
