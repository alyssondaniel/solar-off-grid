## Sequencia recomendada

1. Ler [manual-final-sumry-sp4200.md](manual-final-sumry-sp4200.md)
2. Configurar com [passo-a-passo-painel-sumry-sp4200.md](passo-a-passo-painel-sumry-sp4200.md)
3. Marcar em [checklist-configuracao-sumry-sp4200.md](checklist-configuracao-sumry-sp4200.md)
4. Conferir option/code em [opcoes-paginas-17-21-sumry-sp4200.md](opcoes-paginas-17-21-sumry-sp4200.md)
5. Para consulta curta, usar [guia-rapido-sumry-sp4200.md](guia-rapido-sumry-sp4200.md)
6. Para plano completo, usar [sumry-plano-operacao-cenario-atual.md](sumry-plano-operacao-cenario-atual.md)
7. Se houver necessidade de duas pesadas, validar em [sumry-matriz-duas-cargas-pesadas.md](sumry-matriz-duas-cargas-pesadas.md)
8. Para contingencia, usar [sumry-plano-contingencia.md](sumry-plano-contingencia.md)
9. Se a bateria amanhecer zerada, executar [sumry-amanheceu-zerada-diagnostico-5-min.md](sumry-amanheceu-zerada-diagnostico-5-min.md)
10. Para acao imediata, usar [sumry-cartao-amanheceu-zerada-10-linhas.md](sumry-cartao-amanheceu-zerada-10-linhas.md)
11. Para campo, usar [sumry-cartao-campo-1-pagina.md](sumry-cartao-campo-1-pagina.md)
12. Para operacao diaria de cargas, seguir [../mapa-mestre-operacao.md](../mapa-mestre-operacao.md)
