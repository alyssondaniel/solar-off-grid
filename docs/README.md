# Documentacao do sistema solar

## Objetivo

Este indice organiza os arquivos criados para configurar e operar o inversor Sumry SP-4200 com a bateria Felicity e as 4 placas de 610 W.

## Convencao rapida de termos

- Checklist: lista de verificacao com marcacao [ ]
- Tabela: comparativo rapido ou matriz de decisao
- Protocolo: sequencia curta de acao em evento critico

## Ordem recomendada de uso

### 0. Mapa mestre de operacao

Abrir para escolher rapidamente qual documento usar em cada situacao:

- dia normal
- noite
- fim de semana
- emergencia
- matriz situacao x documento

- `mapa-mestre-operacao.md`

Para trilha especifica do inversor Sumry, abrir:

- `sumry-3.8kw/sumry-mapa-mestre.md`

### 1. Consulta rapida

Abrir primeiro:

- `sumry-3.8kw/guia-rapido-sumry-sp4200.md`

Use este arquivo para lembrar rapidamente:

- parametros finais
- codigos principais do menu
- limites do sistema
- combinacoes de carga mais importantes

### 2. Configuracao no painel

Abrir durante a configuracao:

Use este arquivo na frente do inversor para:

- ajustar cada codigo no display
- validar o comportamento apos salvar

## Parametros finais em ordem de programa

- `01` -> `SBU`
- `02` -> `80A`
- `03` -> `APL`
- `05` -> `USE`
- `08` -> `230V`
- `09` -> `60`
- `11` -> opcional, se quiser limitar carga da rede
- `12` -> `25.5V`
- `13` -> `26.5V`
- `16` -> `OSO` ou `CSO`
- `26` -> `28.4V`
- `27` -> `27.0V`
- `29` -> `24.0V`
- `33` -> `EdS`

## Observacao final

O limite real do sistema esta na bateria. Mesmo com inversor de 3800 W, o uso continuo mais confortavel deve ficar em torno de `2500 W`, e o teto pratico recomendado e `3000 W`.
