# Turno noite - operacao conservadora de cargas

## Objetivo

Este guia define uma rotina noturna mais restritiva para proteger bateria e evitar alarmes.

Janela alvo:

- 19:00-06:00

## Limites noturnos recomendados

- alvo ideal: ate 1200 W simultaneos
- faixa aceitavel: 1200 a 1800 W por tempo curto
- evitar acima de 1800 W no periodo noturno

## Cargas permitidas (prioridade)

| Prioridade | Carga                | Regra pratica              |
| ---------- | -------------------- | -------------------------- |
| 1          | Geladeira            | manter ligada              |
| 2          | Iluminacao essencial | manter apenas o necessario |
| 3          | Cameras e roteador   | manter ligado              |
| 4          | 1 TV + notebooks     | uso normal moderado        |
| 5          | Ventilador           | uso livre                  |

## Cargas com controle

| Carga                             | Regra noturna                                      |
| --------------------------------- | -------------------------------------------------- |
| Ar condicionado 9000 BTU (~800 W) | usar com monitoramento e sem carga pesada paralela |
| Cafeteira (600 W)                 | uso curto e isolado                                |

## Cargas para evitar a noite

- maquina de lavar
- air fryer
- fogao de inducao
- combinacoes de duas cargas acima de 1000 W

## Checklist de decisao (noite)

| Pergunta                                          | Sim/Nao |
| ------------------------------------------------- | ------- |
| Estou abaixo de 1200 W agora?                     | [ ]     |
| Existe alguma carga pesada ligada?                | [ ]     |
| Ar condicionado esta sem outra carga forte junto? | [ ]     |
| Programa 16 esta em OSO (padrao)?                 | [ ]     |
| Houve alarme nas ultimas horas?                   | [ ]     |

## Acao se houver alarme noturno

1. desligar imediatamente carga pesada/resistiva
2. manter apenas cargas essenciais por 10-15 minutos
3. reduzir uso do ar condicionado temporariamente
4. retomar cargas gradualmente, uma por vez

## Regra OSO/CSO para noite

- manter OSO como padrao
- usar CSO apenas em sequencia de noites com baixa geracao no dia anterior e necessidade real de autonomia
- ao normalizar a geracao solar, voltar para OSO

## Decisao direta

Para preservar bateria no turno noite:

- manter somente cargas essenciais + conforto moderado
- transferir toda carga pesada para o horario de sol
